# 설치 및 사용 안내

## 1) 다운로드

→ [최신 버전 받기](https://github.com/whasu677/real-estate-releases/releases/latest)

페이지에서 **`real-estate-app_X.Y.Z_x64-setup.exe`** 파일 하나만 받으면 됩니다.
(`.sig` 와 `latest.json` 은 자동 업데이트가 알아서 쓰니까 무시하셔도 돼요.)

**받은 파일 크기 확인** — 약 **20MB (20,000 KB)** 정도여야 정상.
1KB 또는 그 이하면 다음 항목의 백신 차단을 의심하세요.

## 2) 백신 차단 우회 (알약 / V3 / 안랩 등 한국 백신)

미서명 .exe 라 한국 백신이 자주 차단합니다. 대표 케이스 — 알약 사용 시:

1. 우측 하단 작업표시줄 → **알약 아이콘 우클릭** → "실시간 감시 일시 중지" (10분)
2. 잘못 받아진 1KB 짜리 .exe 와 `.crdownload` 임시 파일 삭제
3. 위 다운로드 링크에서 **다시 다운로드** (약 20MB 정상 크기 확인)
4. 알약 메인 → **"검사 제외"** 또는 **"예외 등록"** 메뉴
5. 다음 두 가지 등록:
   - 방금 받은 `real-estate-app_X.Y.Z_x64-setup.exe`
   - 설치 후 만들어질 폴더: `C:\Program Files\real-estate-app\`
6. **알약 실시간 감시 다시 켜기**
7. 이제 .exe 실행 진행 (다음 단계)

> V3 / 안랩 / 어베스트 등 다른 백신도 동일 패턴 — 일시 중지 → 다운 → 예외 등록 → 재개.

이건 정식 코드 서명 인증서(연 50만원+)를 안 사서 그래요. 악성코드 아니니까 안심하세요. **한 번만 예외 등록하면 끝**. 자동 업데이트도 같은 폴더라 계속 통과됩니다.

## 3) Windows SmartScreen 경고

`.exe` 더블클릭하면 파란 화면이 떠요:

> **Windows 가 PC 를 보호했습니다**
> 인식되지 않은 앱의 시작을 Microsoft Defender SmartScreen 에서 중지했습니다.

→ **"추가 정보"** 클릭 → **"실행"** 버튼 클릭

마찬가지로 한 번만 누르면 다시 안 떠요.

## 4) 설치 마법사

- NSIS 설치 마법사가 떠요. **다음 → 다음 → 설치** 3번이면 끝.
- 설치 후 **데스크탑 바로가기**가 자동으로 생깁니다.
- 시작 메뉴에서도 검색 가능 (`부동산` 입력).

## 5) 첫 실행 — 타겟 등록

앱을 처음 열면 **"시작하려면 타겟을 추가하세요"** 화면이 떠요.

1. **"설정 열기"** 클릭
2. **타겟 추가** 클릭
3. 다음 정보 선택:
   - **지역** — `시/도 → 시·군·구 → 읍·면·동` 3단 드롭다운으로 선택 (지역코드 자동)
   - **부동산 종류** — 상가 / 사무실 / 아파트
   - **거래유형** — 매매 / 전세 / 월세 (복수 선택)
4. **저장**

여러 지역/종류 조합 자유롭게 등록 가능합니다.

> 💡 드롭다운에서 안 보이는 특수 지역이면 폼의 **"직접 입력"** 토글로 cortarNo 직접 입력 가능.

## 6) 사용

- **새로고침** 버튼 → 네이버에서 최신 매물 가져옴
- **자동 갱신 ON** → 설정한 주기마다 자동 폴링 (기본 10분). 상태바에 다음 갱신 시각 표시.
- 새 매물 발견 → **Windows 알림** + 화면 상단 빨간 배너 + 행 강조
- 매물 행 더블클릭 → 네이버 상세 페이지 열림

## 7) 자동 업데이트

새 버전이 나오면 **앱이 알아서 1시간마다 확인**합니다. 또는 **설정 → "업데이트 확인"** 으로 즉시.

새 버전 발견 시 상단에 노란 배너 → **"지금 업데이트"** 클릭 → 다운로드 + 자동 재시작.

> 자동 업데이트는 백신 예외 등록한 폴더 안에서 일어나므로 한 번만 예외 등록하면 이후엔 자동 통과.

## 트러블슈팅

**다운받은 .exe 가 1KB 짜리에요**
→ 백신 차단입니다. "2) 백신 차단 우회" 절차 진행.

**"조회 실패: ..."** 같은 에러
→ 네이버 일시 차단 또는 네트워크 문제. 잠시 후 재시도.

**알림이 안 와요**
→ Windows 설정 → 시스템 → 알림 → `real-estate-app` 켜져 있는지 확인.

**앱이 안 켜져요 / 흰 화면**
→ 설정 → "폴더 열기" 의 `sidecar.log` 파일 내용을 개발자에게 전달.

**완전히 삭제**
→ 제어판 → 프로그램 추가/제거 → `real-estate-app` 제거.
   설정 데이터 (`~/.real-estate-module/`) 는 따로 남으니 필요 없으면 수동 삭제.
