# 설치 및 사용 안내

## 1) 다운로드

→ [최신 버전 받기](https://github.com/whasu677/real-estate-releases/releases/latest)

페이지에서 **`real-estate-app_X.Y.Z_x64-setup.exe`** 파일 하나만 받으면 됩니다.
(`.sig` 와 `latest.json` 은 자동 업데이트가 알아서 쓰니까 무시하셔도 돼요.)

## 2) Windows 경고 무시

`.exe` 를 처음 실행하면 파란 화면이 떠요:

> **Windows 가 PC 를 보호했습니다**
> 인식되지 않은 앱의 시작을 Microsoft Defender SmartScreen 에서 중지했습니다.

→ **"추가 정보"** 클릭 → **"실행"** 버튼 클릭

이건 정식 코드 서명 인증서(연 30만원+)를 안 사서 그래요. 악성코드 아니니까 안심하세요. 한 번만 누르면 됩니다.

## 3) 설치 마법사

- NSIS 설치 마법사가 떠요. **다음 → 다음 → 설치** 3번이면 끝.
- 설치 후 **데스크탑 바로가기**가 자동으로 생깁니다.
- 시작 메뉴에서도 검색 가능 (`부동산` 입력).

## 4) 첫 실행 — 타겟 등록

앱을 처음 열면 **"시작하려면 타겟을 추가하세요"** 화면이 떠요.

1. **"설정 열기"** 클릭
2. **타겟 추가** 클릭
3. 다음 정보 입력:
   - **지역명** — 예: `대전 서구 관저동`
   - **지역코드** (10자리) — 네이버 부동산에서 동 검색 후 URL 의 `cortarNo=...` 부분 복사
   - **부동산 종류** — 상가 / 사무실 / 아파트
   - **거래유형** — 매매 / 전세 / 월세 (복수 선택)
4. **저장**

여러 지역/종류 조합 자유롭게 등록 가능합니다.

> 💡 **지역코드 찾는 방법**: [네이버 부동산](https://land.naver.com) → 원하는 동 검색 → 브라우저 주소창의 `cortarNo=` 뒤 10자리 숫자

## 5) 사용

- **새로고침** 버튼 → 네이버에서 최신 매물 가져옴
- **자동 갱신 ON** → 설정한 주기마다 자동 폴링 (기본 10분)
- 새 매물 발견 → **Windows 알림**으로 통보 + 화면 상단 빨간 배너
- 매물 행 클릭 → 네이버 상세 페이지 열림

## 6) 자동 업데이트

새 버전이 나오면 **앱이 알아서 1시간마다 확인**합니다. 또는 **설정 → "업데이트 확인"** 으로 즉시 확인 가능.

새 버전 발견 시 상단에 노란 배너가 떠요 → **"지금 업데이트"** 클릭 → 다운로드 + 자동 재시작.

## 트러블슈팅

**"조회 실패: ..."** 같은 에러가 떠요
→ 네이버가 일시적으로 차단했거나 네트워크 문제. 잠시 후 다시 시도.

**알림이 안 와요**
→ Windows 설정 → 시스템 → 알림 → `real-estate-app` 켜져 있는지 확인.

**앱이 안 켜져요 / 흰 화면**
→ 설정 → "폴더 열기" 의 `sidecar.log` 파일 내용을 개발자에게 전달.

**완전히 삭제하고 싶어요**
→ 제어판 → 프로그램 추가/제거 → `real-estate-app` 제거.
   설정 데이터 (`~/.real-estate-module/`) 는 따로 남으니 필요 없으면 수동 삭제.
